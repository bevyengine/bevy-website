How are games actually displayed to the person playing them?
Through a **Camera**, of course!
Well, technically they'll look at a screen, which then displays an image that's taken from a camera, but we'll talk about that later.
The point is that the easiest path to showing the user something in a Bevy game is to use a [`Camera`].

You can think of a [`Camera`] like a window into the `World` that displays what the user should see from a given perspective.
Much like how looking out of a real-world window will only display what is outside that specific window, a Bevy `Camera` will only display what is in front of it.


[`Camera`]: https://docs.rs/bevy/latest/bevy/camera/struct.Camera.html
